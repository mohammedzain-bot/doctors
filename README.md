# Dr. John Smith · Cardiologist Portfolio

A premium, modern, mobile-first website for a medical specialist with full-page animated background and glassmorphism UI.

## Features
- **Mobile-First UX**: Tailored for mobile screens with touch-friendly navigation, sticky bottom action bar, and responsive layout.
- **Glassmorphism Aesthetic**: Translucent frosted glass cards with backdrop blurs and subtle borders.
- **Animated Holographic Background**: Full-viewport animated background with gentle Ken Burns motion and breathing luminosity.
- **Key Sections**:
  - Hero with appointment CTAs & quick stats
  - About & qualifications
  - Clinical specializations & expertise
  - Experience & career milestones
  - Direct appointment & call actions (`+91 94954 92013`)

## Files
- `index.html` - Semantic markup and structural sections
- `style.css` - Dark luxury medical styling, tokens, glassmorphism, responsive breakpoints
- `script.js` - Mobile navigation, scroll transitions, micro-interactions
- `hero-bg.png` - Visual background asset
